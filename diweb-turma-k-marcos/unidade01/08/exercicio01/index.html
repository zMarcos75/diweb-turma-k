Tipos estilos em CSS

01 Estilo inline

Permite a estilização dos elementos individualmente. Utilizamos o atributo style para criar a regra. Estiliza um componente por vez. Não tem reaproveitamento.

02 Estilo incorporado

Permite a estilização de mais de um elemento dentro da página. É utilizado quando precisamos definir o estilo para vários elementos dentro de uma mesma página. Utiliza a tag . Permite reaproveitamento somente dentro da mesma página.

01 Estilo externo

Utiliza um arquivo externo que é ligado a uma ou mais páginas HTML. O mais indicado e utilizado. Criamos um arquivo externo com todas as regras para os elementos. Utiliza a tag para sua definição. Pode ser reaproveitado por diversas páginas.
